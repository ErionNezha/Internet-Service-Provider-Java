# 🌐 Internet Service Provider

Port web i aplikacionit Java Swing për ISP — panel admini me plane interneti, klientë, ankesa dhe punonjës.

## 🚀 Si ta hapësh

Hap `index.html` — skeda **Live Demo** ekzekuton demo-n direkt në browser, skeda **Kodi Burim** tregon kodin e plotë (demo + origjinali i paprekur).
